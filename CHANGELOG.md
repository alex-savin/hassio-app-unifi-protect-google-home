# Changelog

Release notes for the **UniFi Protect → Google Home** add-on are maintained
in [unifi-protect-google-home/CHANGELOG.md](unifi-protect-google-home/CHANGELOG.md) —
that copy is canonical because Home Assistant Supervisor reads the
`CHANGELOG.md` inside the add-on directory to render the "What's new" panel
in the add-on store.

Versioned releases are also published with generated notes on the
[GitHub releases page](https://github.com/alex-savin/hassio-app-unifi-protect-google-home/releases).
